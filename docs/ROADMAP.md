# Roadmap

## v0.8.0 — local training dashboard [current]

- One-command contributor and operator application.
- Live campaign/routing telemetry and resource controls.
- Authenticated campaign setup, planning, queueing, and final evaluation.
- Cross-platform launchers and package optimization.

## v0.7.0 — CIFAR-100 swarm campaign [complete]

- Official CIFAR-100 Python archive download, integrity verification, and secure extraction
- Explicit official fine-label to Native10 coarse-colony mapping
- 45k train / 2.5k selection / 2.5k replication / 10k test boundary
- Spatial 4×2 patch adapter for eight sensory field tissues
- Deterministic CIFAR crop/flip augmentation
- Compact uint8 field-training transport
- Real routing-gap report and architecture-search planner
- Hard-negative scout search and field-routing-margin search
- Bounded expert, branch, memory, repair, scout, and field contribution tasks
- One-shot selection and replication folds
- Final test-only evaluation and external baseline comparison
- Routing, search-yield, and contributed-worker-time telemetry

## v0.7.x — First public campaign evidence

- Import the established trained Native10 checkpoint and publish its conversion/equivalence report
- Run the campaign against the official archive
- Publish initial, per-round, and final official-test accuracy
- Publish routing-gap closure by round and by category
- Compare with the established centralized baseline evidence artifact
- Report gain per donated worker-hour, verifier-hour, transferred byte, and coordinator-hour
- Publish verifier checkpoint cache-hit and cold-transfer rates
- Measure ARM64/x86_64 candidate and replay agreement in the live network

## v0.8 — Multi-lane campaign throughput

- Precommit multiple disjoint category lanes in one hidden-evidence tournament
- Select one statistically valid delta per non-conflicting lane
- Replicate and promote the combined root atomically
- Merkle/chunk checkpoint transport and incremental verifier caches
- Regional object storage for canonical checkpoints and validation shards
- Multiple independently auditable coordinator witnesses

## Longer-term

- External anti-Sybil, stake, reputation, or verified-principal policy
- Data contamination and duplicate-image audits
- Additional real datasets and continual-learning campaigns
- Privacy-preserving contributor data and verification
